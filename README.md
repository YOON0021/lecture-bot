# 📚 Lecture Bot

강의 자료(PDF, PPTX)를 텔레그램으로 보내두고, **폰에서 질문하면 강의 자료를 근거로 답해주는** RAG 챗봇입니다.

## 기능

| 기능 | 사용법 |
|---|---|
| 과목별 자료 관리 | `/subject 컴퓨터네트워크` 후 PDF/PPTX 전송 (캡션에 과목명을 써도 됨) |
| 질문 답변 | 그냥 메시지로 질문 → 답변 + 출처 페이지 (`📚 3주차.pptx p.5`) |
| 이어지는 질문 | "그거 예시 들어줘"처럼 최근 3개 대화를 기억 (`/reset`으로 초기화) |
| 파일 요약 | `/summary` → 파일 선택 → 핵심 개념 + 시험 포인트 |
| 퀴즈 | `/quiz 5` → 텔레그램 퀴즈 투표로 4지선다 문제 풀기 (해설과 출처 포함) |
| 파일 관리 | `/files` → 버튼으로 삭제, 같은 이름으로 다시 올리면 교체 |

- PPTX는 슬라이드 본문, 표, **발표자 노트**까지 읽습니다.
- 검색은 벡터 검색 + BM25 키워드 검색을 합친 하이브리드 방식입니다 ([pdf-rag-qa](https://github.com/YOON0021/pdf-rag-qa)에서 가져옴).
- 과목끼리 자료가 섞이지 않게 현재 과목 안에서만 검색합니다.

## 구조

```
[텔레그램] ─► bot.py ─┬─ 파일 ─► rag/loader.py (PDF/PPTX → 페이지별 청크) ─► rag/store.py (Chroma + BM25)
                      ├─ 질문 ─► 과목 내 하이브리드 검색 ─► rag/llm.py (Claude, 스트리밍) ─► 답변 + 출처
                      ├─ /summary ─► 파일 전체 텍스트 ─► Claude 요약
                      └─ /quiz ─► 무작위 청크 ─► Claude 구조화 출력(JSON) ─► 텔레그램 퀴즈 투표
```

## 설치

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 검색 → `/newbot`
2. 봇 이름과 아이디(`..._bot`으로 끝나야 함) 입력
3. 받은 토큰(`123456789:ABC...`)을 복사

### 2. 실행
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # ANTHROPIC_API_KEY, TELEGRAM_BOT_TOKEN 입력
python bot.py
```

### 3. 내 계정만 쓸 수 있게 설정
1. 봇에게 `/start`를 보내면 **내 사용자 ID**를 알려줍니다.
2. `.env`의 `ALLOWED_USER_IDS`에 그 ID를 넣고 봇을 재시작합니다.

> 허용되지 않은 사람은 봇을 쓸 수 없습니다. 봇 아이디만 알면 누구나 말을 걸 수 있으므로, 설정하지 않으면 내 API 요금이 쓰일 수 있어서 기본적으로 막아두었습니다.

## 계속 켜두기

봇은 `python bot.py`가 실행 중일 때만 답합니다.

- **맥에서 돌리기**: 맥이 잠자기에 들어가면 멈춥니다. `caffeinate -i python bot.py`로 실행하면 켜져 있는 동안 잠들지 않습니다.
- **서버에서 돌리기**: 항상 쓰려면 클라우드 서버(Oracle Cloud 무료 티어 등)에 올리는 게 좋습니다. 임베딩 모델 때문에 메모리가 1GB 이상 필요합니다.

## 참고

- 텔레그램 봇은 **20MB 이하** 파일만 받을 수 있습니다.
- 스캔한 이미지 PDF(텍스트 선택이 안 되는 PDF)는 아직 지원하지 않습니다.
- `.ppt`(옛날 형식)는 PowerPoint에서 `.pptx`로 저장해서 보내주세요.
- 데이터는 `data/` 폴더에 저장됩니다 (벡터 DB, 현재 과목 등 봇 상태).
